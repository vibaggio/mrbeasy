Modelo evolutivo

Escolha o tipo de dado e o modelo de substituição. Se seus dados têm mais de um gene/região, ative partições e defina um modelo para cada uma.

Detectado automaticamente a partir do arquivo quando possível — ajuste se necessário.
Meus dados têm mais de uma partição (ex: genes diferentes)
Cria blocos charset e partition com modelo independente por partição
Padrão do MrBayes é 4. Mais categorias aproximam melhor a distribuição contínua, ao custo de mais tempo de análise.

Nomes como TrN, TIM1-3, TPM1-3 e TVM são casos intermediários entre HKY e GTR (algumas das 6 taxas amarradas entre si) — o MrBayes não tem um atalho de nome para eles isoladamente; use Mixed acima, que testa automaticamente toda essa família (essas variações inclusive) e estima a probabilidade de cada uma. O modelo FreeRate (+R) de programas de máxima verossimilhança (IQ-TREE, RAxML) não existe no MrBayes — apenas Gamma (+G) e proporção de invariáveis (+I) estão disponíveis.

Fixar manualmente as taxas de substituição
Em vez de estimar, usa os valores relativos que você informar abaixo (prset revmatpr=fixed(...))
Taxas relativas de substituição (par de bases)

Valores relativos (não precisam somar 1) — ex: use os resultados de um modelo já estimado antes, ou taxas publicadas na literatura para o seu grupo. Só se aplica à estrutura de 6 taxas. Dica avançada: para aproximar manualmente um modelo como TIM (sem a incerteza do Bayesiano), repita o mesmo valor nos pares que esse modelo trata como iguais.

Partições

Informe o intervalo de sítios de cada gene (ex: 1–520). Confira esses números no seu alinhamento — a página não adivinha onde um gene termina e outro começa. Taxas fixas não estão disponíveis por partição; a categoria gamma (+G) definida acima vale para todas.

05

Onde a análise vai rodar?

Isto é sobre o computador onde o MrBayes vai processar a análise — não sobre esta página, que já funciona em qualquer navegador, em qualquer sistema (Windows, Ubuntu, macOS). O bloco de comandos do NEXUS é o mesmo nas três opções abaixo; o que muda é a instrução de execução (e o uso de MPI).

Sugerido = nruns × nchains (ajustado automaticamente ao mudar o passo 03). Não ultrapasse o nº de núcleos disponíveis (confira com nproc no terminal do Ubuntu).

O WSL2 expõe todos os núcleos do seu processador ao Ubuntu — é a forma mais simples de sair do limite de threads do MrBayes nativo do Windows. O .bat gerado cuida de tudo: entra no WSL, detecta núcleos, instala o MrBayes se necessário e roda a análise com o paralelismo ideal. Você só precisa dar dois cliques no arquivo.

Usar MPI (paraleliza as cadeias entre núcleos)
Requer o pacote mrbayes-mpi instalado no WSL (sudo apt install mrbayes-mpi)
Se instalou via apt, deixe mb. Se compilou o MPI manualmente, use mb-mpi ou o caminho do binário.
