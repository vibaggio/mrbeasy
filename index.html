Guia de Uso e Explicação dos Parâmetros

Passo a Passo Rápido

  1. Instalação Inicial: Se for a primeira vez no PC, clique no botão verde para baixar e rodar o instalador de dependências.
  2. Upload (Dica: Prefira FASTA!): O recomendável é arrastar arquivos `.fasta` limpos. O conversor inteligente criará o NEXUS perfeitamente otimizado. Arquivos já em `.nexus` serão aceitos e limpos também.
  3. Configuração: Preencha as gerações e ajuste os modelos (ou deixe no automático/mixed).
  4. Gerar e Rodar: Clique no botão azul final. Dois arquivos serão baixados. Coloque-os na mesma pasta e dê duplo clique no arquivo .bat para iniciar a análise.

Explicação das Configurações

  • Ambiente de Execução:
    Windows: Roda em thread única (processamento serial). Útil para matrizes muito curtas.
    Ubuntu/WSL (MPI): Divide o processamento entre vários núcleos do computador. Obrigatório para grandes matrizes (reduz o tempo drasticamente).
  • Gerações (ngen): O número de ciclos da simulação (MCMC). Se ao fim o "Average Standard Deviation" for > 0.05, você precisará gerar uma nova análise aumentando este valor (ex: de 1.000.000 para 5.000.000).
  • Amostragem (samplefreq): De quantas em quantas gerações uma árvore é salva no arquivo. Padrão: 1000. Evita que os arquivos de saída fiquem gigantescos.
  • Threads/Cadeias: Quantidade de caminhos paralelos na simulação MCMC (nchains). O padrão do MrBayes é 4. Deve obrigatoriamente ser igual ao número de Threads que você destinará no ambiente MPI.
  • Modelo de Evolução (nst): Dita como ocorrem as substituições de nucleotídeos.
    - Misto: O MrBayes pula entre modelos e escolhe o melhor sozinho.
    - GTR (6): Taxas independentes para cada transição/transversão.
    - HKY (2): Uma taxa para transições, outra para transversões.
  • Variação de Taxas (rates): Como as mutações variam ao longo dos sítios (colunas) do alinhamento.
    - invgamma (I+G): Sítios invariáveis + variação Gamma (mais comum e flexível).
    - gamma (G): Variação segue uma distribuição Gamma.
  • Outgroup: Define fisicamente onde fica a raiz da sua árvore filogenética. Insira o nome exato (letras e números) de uma espécie distante incluída no seu alinhamento.
  • Fixar Taxas Relativas: Se você rodou sua matriz antes no IQ-Tree ou jModelTest e ele indicou o modelo GTR com taxas numéricas específicas (A-C, A-G, etc.), digite-as aqui. Preencher isso força o modelo GTR automático e acelera a convergência do MrBayes.
